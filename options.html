Settings

Control how RAIN surfaces on the pages you investigate.

Floating hunt button

Shows the RAIN button beside highlighted text on any page. Click it to open the hunt menu, including on sites that replace the right-click menu with their own. Dismiss it with Esc or by clicking elsewhere.

Force native right-click with Shift

Hold Shift while right-clicking to skip a site's custom context menu and open the browser's own menu, where the RAIN hunt options are. Normal right-clicks are unaffected.

Hunt hotkey: Alt+R

Opens the hunt menu for the highlighted text. If nothing is highlighted, or the selection cannot be read, the RAIN side panel opens instead so the indicator can be pasted. Key combinations already used by the browser cannot be assigned.

Welcome to RAIN

RAIN, the Right-click Analyst's IOC Navigator, is named after a particularly relentless miniature dachshund. It is a dedicated SOC tool designed to speed up the OSINT hunting of IOCs. Built to eliminate the friction of manual copy-pasting and excessive tab switching, RAIN bridges the gap between web text and actionable threat intelligence.

Highlight an IOC anywhere and RAIN cleans the string, classifies it, and launches your investigation.

Four Ways to Hunt

All four surfaces apply the same cleaning, classification, and tools.

  • Right-click menu: highlight an IOC, right-click, and choose RAIN - Hunt IOC. The menu lists every category, so select the one that matches the indicator. If a site shows its own right-click menu instead, hold Shift while right-clicking to get the browser menu.
  • Floating button: highlight text and click the RAIN button that appears beside it. RAIN classifies the indicator automatically and shows the matching tools. If the detected type is wrong, or the indicator wasn't recognized, switch it with the type selector at the top of the menu. Drag the menu by its header to move it; RAIN keeps it within the visible page. Press Esc or click elsewhere to dismiss.
  • Hunt hotkey (Alt+R): opens the same menu for the highlighted text. Change the key in Settings.
  • Side panel: docks to the browser window whenever the in-page menu isn't possible: nothing highlighted, browser pages, tabs opened before RAIN was installed, or portals that hide their selection. It opens prefilled with the selection where RAIN can read it. Open it any time from the browser's side panel menu: paste an indicator, adjust the type, and hunt.

Supported IOC Types

The floating button and hotkey classify indicators automatically; the right-click menu leaves the choice to you.

  • IP addresses: IPv4 and IPv6.
  • Domains & URLs: bare domains, subdomains, and full URLs.
  • File hashes: MD5, SHA-1, and SHA-256, detected by length.
  • Accounts & emails: email addresses and UPNs.
  • Vulnerabilities: CVE identifiers, e.g. CVE-2024-21412.
  • User-Agent strings: common browser, crawler, command-line client, and application user agents. Parse through Microsoft Defender's KQL parse_user_agent() function or GCHQ CyberChef's Parse User Agent recipe, then pivot to exact-string lookups when needed.

Yeet Search

One click, every relevant tool.

  • Yeet Search opens the IOC in all tools for its category at once, including Defender Advanced Hunting. Available for IPs, domains, hashes, and CVEs.
  • Tabs open in the background and are collected into a single collapsed, colour-coded tab group (blue = IP, green = domain, orange = hash, red = CVE), so the current workspace is not disturbed.
  • Close the whole group when the pivot is done to keep the tab bar clean.

Defender Advanced Hunting

Hunts that target Defender AHQ inject a ready-to-run KQL query.

  • RAIN opens security.microsoft.com Advanced Hunting and inserts the KQL template for the IOC type, with the placeholder replaced by the cleaned indicator.
  • The query is inserted, never executed. Review it and press Run in the portal yourself.
  • An active Defender portal session with Advanced Hunting access is required. RAIN waits up to 30 seconds for the query editor to finish loading.
  • Every query is customizable per IOC type in the KQL Templates tab.

Automatic Refanging & Cleaning

RAIN sanitizes and refangs highlighted indicators on the fly before executing search queries.

  • Protocol Refanging: converts defanged protocols like hxxps://, hxxp://, meows://, or meow:// back to standard https:// or http://.
  • Obfuscated Dots, Colons & Ats: replaces bracketed, parenthesized, or verbal representations (e.g., [.], (.), {.}, [dot], (dot), [:], (:), [@], [at]) with the real characters.
  • Surrounding Trimming: strips accidental leading or trailing quotes, parentheses, brackets, or angle brackets highlighted along with the IOC.

Variables & Placeholders

Each KQL template contains one placeholder, replaced with the cleaned IOC when the query is inserted into Defender.

IP_VALUE Replaced with the extracted IPv4 or IPv6 address.
DOMAIN_VALUE Replaced with the extracted domain name or URL.
HASH_VALUE Replaced with the extracted MD5, SHA-1, or SHA-256 file hash.
ACCOUNT_VALUE Replaced with the extracted user account name, email address, or UPN.
CVE_VALUE Replaced with the extracted CVE identifier (e.g., CVE-YYYY-NNNN).

OPSEC Reminder

Think before you pivot.

  • Every hunt sends the indicator to the external service you choose. Searches on public platforms may be visible to the platform, its users, and in some cases the adversary.
  • Avoid submitting internal hostnames, employee accounts, or indicators from targeted intrusions to public tools unless your team's OPSEC policy allows it.
  • RAIN itself stores nothing outside your browser and sends no telemetry. Templates and settings live in local extension storage only.

Troubleshooting

Quick answers for the common snags.

  • RAIN doesn't appear on a page: pages opened before RAIN was installed or updated need a refresh. Browser-internal pages (chrome://), the Chrome Web Store, and the built-in PDF viewer do not allow extensions to run; on those pages the hunt hotkey opens the RAIN side panel instead.
  • No right-click option: the menu only appears while text is highlighted. If the site shows its own menu, hold Shift while right-clicking, or use the floating button.
  • KQL didn't appear in Defender: confirm the portal session is signed in and the Advanced Hunting editor has finished loading. The query is inserted into the editor, not executed.
  • Floating button doesn't show: check it is enabled in Settings. Selections shorter than 2 or longer than 500 characters are ignored.
  • Hotkey opens the side panel even though text is highlighted: some portals, including Microsoft Defender, render content inside frames or shadow DOM where the selection cannot always be read. RAIN prefills the panel when it can; otherwise copy the indicator and paste it in. The right-click menu still works on these pages because the browser supplies the highlighted text itself.
  • Hotkey does nothing: another extension or the browser may already use that combination. Set a different one via Settings → Change shortcut.
